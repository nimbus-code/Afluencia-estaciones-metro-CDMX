# Número de pasajeros por estación del metro, Feb (2026)

Este proyecto tiene la finalidad de mostrar el proceso para lograr un mapa dinámico exportado en html y una gráfica del top 10 de estaciones que son más usadas en la CDMX. Los datos fueron obtenidos del Portal de Datos Abiertos de la CDMX (datos.cdmx.gob.mx), donde se limpiaron y transformaron 34,515 filas de información, también se usaron dos archivos de tipo shape descargadas del mismo sitio para realizar el mapa. Las herramientas utilizadas fueron: Colab (google) y las bibliotecas de Python, **Pandas, Matplotlib y Geopandas**
